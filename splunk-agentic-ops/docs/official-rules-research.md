## Strategic Interpretation

This hackathon is not asking for generic AI demos.

It is asking for AI-powered operational systems grounded in Splunk data.

The product must visibly use Splunk as an operational data layer, not merely mention Splunk in a README.

Strong directions:

- incident investigation assistant
- alert triage workflow
- network troubleshooting agent
- productivity tool for Splunk app developers
- agent telemetry and governance

AgentOps Flight Recorder fits best as Platform & Developer Experience with an Observability angle.
